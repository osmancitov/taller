# Taller

Un taller es un lugar donde se trabaja una obra. La palabra viene del francés *atelier*, que antes nombró un montón de madera y luego el lugar donde se la trabajaba.

Aquí se estudia y se prueba. Los cuadernos guardan preguntas, notas, frases y herramientas; pueden cambiar mientras el trabajo sigue.
